# 小暖 AI 备孕助手 Demo

微信原生小程序（JavaScript / WXML / WXSS）。当前只注册两个页面：聊天主页面 `pages/chat/chat` 和二级周期记录页 `pages/record/record`，没有 tabBar。

## 启动

1. 下载并解压项目，在微信开发者工具中导入包含 `app.json` 和 `project.config.json` 的目录。
2. 使用你有开发者权限的小程序 AppID；当前项目已保留配置的正式 AppID。不要上传 AppSecret 或服务端密钥。
3. 保持 `utils/constants.js` 的 `USE_CLOUD=false`，点击编译即可使用本地问答、聊天保存与周期记录；本轮已撤回模型API和云端记忆，不需要部署云函数。
4. 真机预览/调试需登录有权限的微信账号。实际代码包大小以开发者工具为准；`packOptions.ignore` 已排除设计参考、测试和说明文件，避免把开发资料打进2MB主包。

## 当前行为与限制

- 文字咨询使用本地知识与Skill规则，不调用模型API，不读写云端记忆。聊天记录与周期记录保存在本机。
- 首页和咨询标签使用完整预设问句；报告中的“生成备孕计划”直接整理当前报告的建议与分析，不重新走关键词路由。
- 反馈保存在本机最近50条，尚无服务端反馈通道。普通“没帮到我”反馈提示补充问法；内容准确性反馈提示核实；高风险只保留消息内风险卡，不重复显示底部横幅。
- 咨询服务卡为示例，尚未接入真人备孕师预约或服务记录系统。
- 自评分数、箭头和雷达图使用既有 Demo 计分规则，未经医学验证，不代表诊断、生育能力或受孕概率。
- 周期记录页、云函数模式、图片和语音咨询不在本次评审修改范围内；现有能力边界不变，不据此宣称已完成这些能力的验收。

## 明确问题被“怎么办”兜底截走的修复

基础咨询只在整句属于模糊表达时追问，不再因具体问题带有“怎么办”直接回复“当然可以”。“备孕一年都没怀上孕怎么办”等问法复用已有生育评估问答；仅凭未孕描述不诊断不孕，也不按急症输出。试纸阴性疑问仍走验孕科普；大量出血、剧痛、腹痛伴出血仍优先走原高风险规则。

新增测试覆盖截图原句和9种相近表达、模糊短句、验孕疑问及混合高风险症状；未更改页面、入口或视觉，未恢复此前已撤销的周期解读流程。

本次新增医疗相关提示（供确认）：“你想了解备孕一段时间仍未怀孕该怎么办，我们先看何时需要评估，以及可以准备哪些信息。”“双方一起整理既往检查和周期记录，预约妇科或生殖医学门诊咨询；不要自行使用促排药。”年龄与时长说明复用已有本地问答，仍需结合实际未避孕性生活情况、病史和症状，不是诊断。


“小暖分析”中的重点词组按本地显示规则标为主题粉色 #FF4089：正文/折叠预览的关键词每段最多3处、每条建议最多1处；分析中每个编号标题、分周标题、建议标签，以及“可以补充／请补充”后的当行问题全部标为主题色，不占关键词数量；否定指令尽量整句标色。原始回答、复制文本、反馈数据及免责声明内容不变，旧消息也支持。未命中词表的文本保持原色；该规则只辅助阅读，不作新的医学判断。


文字咨询发送后显示白色气泡内的三个主题粉色圆点，依次上下跳动与明暗变化；无障碍标签保留“小暖正在思考中”。本地Demo约等待1.2秒再回填回答；这是本地演示延时，不是模型推理时间。普通失败会结束加载并提示重试。每张“小暖分析”卡片右上角可“复制文字”，复制该条完整原始回答（含建议和安全提醒），不受折叠或粉色高亮影响；复制成功/失败有提示。


基础体温路由：询问“怎么记录”“什么时候量”命中cycle-temperature固定问答，进入知识咨询；明确要求根据个人记录分析周期阶段时，风险规则之后优先进入周期分析。没有记录时列出经期起止日期、平均周期长度和经期长度；现有记录页不保存连续体温数据，回复不会声称已分析个人体温曲线。已有月经记录的周期日期计算逻辑保持不变。

本次补充的测量方法文案供确认：基础体温通常在每天早晨醒来后、起床活动前测量，尽量保持相近时间，使用同一支体温计和相同测量部位，按说明操作；记录日期、时间、温度及睡眠不足、发热或饮酒等干扰。白天活动后的体温不能直接当作基础体温；连续变化只能提供回顾性线索，一次升高不能确认排卵或怀孕，也不能作为用药依据。仍为本地科普草案，非医学诊断。


首页“备孕计划”回复现提供4周通用准备安排，并给出今天/本周/每天的具体行动；“知识科普”回复解释6个主题和常见误区，不再只罗列类别。仅这两个FAQ支持专用开场，其他回复不变；长文沿用原来的“展开全部”和“复制文字”。完整新增科普文案见design-reference/home-guide-copy.md，仍为待确认的本地科普草案。


围绝经期/绝经作为次级本地科普接入，未新增首页入口或页面：支持区别与定义、月经变化、40岁后备孕、潮热/睡眠/情绪变化，以及绝经后再次出血。明确话题不进入个人周期计算；出血/疼痛和用药仍遵循风险优先级，大量出血、剧痛、腹痛伴出血仍保留原高风险处理。文案见design-reference/menopause-copy.md（本地科普草案，待确认与专业审核）。

## 本机聊天记忆

最近100条文字消息保存在微信本机缓存，回答回填及页面退出时保存。重新打开保持首页，通过顶部时钟查看；旧回答不重播逐字动画。顶部加号开始新对话前确认清除聊天记录，周期记录保留。图片/报告类消息不进入该文字缓存，不保存图片文件；当前不是云端同步或任意多轮语义记忆，不跨设备，清除小程序数据后会丢失。不新增个人健康档案或自动推断个人信息。微信真机重启、清除确认和存储空间不足仍需实际复核。


逐字回答期间聊天区持续跟随底部，避免把内容增长误判为用户离开底部；手指下拉查看旧消息时暂停跟随，点原有回到底部按钮恢复。逐字期间关闭重复的滚动动画以减少追赶延迟，回答结束后恢复原滚动动画。只改滚动绑定与逻辑，不改页面样式。已通过模拟滚动/触摸测试，微信原生滚动手感及键盘联动仍待真机复核。


周期记录的身体状态标签由JS计算选中映射，历史记录由JS生成状态文字，避免WXML调用不支持的indexOf/join；原标签样式与布局保持不变。多选、取消、保存数据和保存后重置已通过模拟测试，微信实际点击待复核。
