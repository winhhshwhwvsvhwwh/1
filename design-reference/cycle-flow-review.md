## 实际验证与局限

- Node 模拟微信 API：空记录从首页进入记录页，保存后自动发送固定问句；已有记录直接解读；保存较旧日期也使用刚保存的ID；无匹配ID不估算；独立打开记录页可回到原聊天页。
- 实际反馈方法：默认不满意、7个原因、本地保存、已反馈状态；普通反馈继续提问设置输入聚焦；“内容有误”可调用既有就医指引弹窗；高风险分支由既有测试覆盖。
- README 7个原有测试通过：offlineKnowledge、reviewFlows、feedback、scrollShortcut、assessmentReport、radarTooltip、componentAssets。另新增 cycleFlow 通过。
- WXML/WXSS 编译通过。390×844 浏览器辅助渲染：首页原生标签可见、咨询示例标签可见；问卷赞踩图与两个半宽点击容器边界对应；按阶段/按需求图标容器与文字未重叠。浏览器截图在执行环境临时目录，不是微信原生截图。

## 新增/调整的周期相关文案（供确认）

模板变量为用户记录或日期规则计算值，不是医生结论。

1. “本次使用你保存的 {开始日期} 至 {结束日期} 记录（平均周期 {周期长度} 天、经期 {经期长度} 天）。”
2. “暂时没有可用于估算的周期记录。”
3. “请先在「周期记录」填写并保存经期开始日期、结束日期、平均周期长度和经期长度，再点「查看周期解读」。缺少记录时无法估算当前阶段。”
4. “这条记录的开始日期或周期参数不完整、无效或不适合本模板估算，暂不提供具体阶段。请检查日期、平均周期长度和经期长度；如周期明显异常，请咨询医生。”
5. “根据这条记录估算，目前可能处于{阶段}，约为周期第{天数}天（按平均周期{长度}天推算）。”
6. “记录开始日期已超过一个平均周期；这里按平均周期外推，若其后已有新经期，请先更新记录，不能据此确认当前阶段。”
7. “仅按日期粗略估算，排卵附近可能在周期第{起始}—{结束}天；实际排卵可能提前或推迟，不能用于确认排卵、怀孕或避孕。”
8. “持续记录有助于核对规律，但日期估算仍可能有偏差。”
9. “日期估算可能接近排卵期，仅供记录参考，不据此确认已排卵。”
10. “可连续记录排卵试纸或基础体温变化，必要时由医生结合检查评估。”
11. “日期估算不能排除排卵时间变化，可继续规律作息并记录身体变化。”

保留原有风险识别、免责声明和负向反馈的医疗/普通原因分支；未增加用药判断。
