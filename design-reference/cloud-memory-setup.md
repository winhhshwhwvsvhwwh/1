# 云端个人档案与连续对话

本轮停用报告图片识别，第三个快捷入口改为“个人档案”。不启用旧的全局 USE_CLOUD，周期记录仍在本机。个人档案和文字对话由独立 companionMemory 云函数管理。

## 部署（代码不能替代账号配置）

1. 更新项目代码。在微信开发者工具右键 cloudfunctions，选择 cloud1 对应的环境 cloud1-d4gc5cmbyc4c65482。
2. 右键 companionMemory → 上传并部署：云端安装依赖。本轮不用部署旧 reportInterpretation 或旧 aiChat。
3. 在云开发数据库创建集合 xiaonuan_memory。权限设置为自定义：`{"read":false,"write":false}`，禁止小程序直接读写；云函数通过服务端 SDK 访问。仅云端代码依据 wx.getWXContext().OPENID 定位本人的文档。不要设成所有人可读写。
4. companionMemory → 版本与配置 → 配置 → 高级配置：超时60秒，内存256MB，选择平台支持的Node运行环境。
5. 环境变量：AI_API_KEY 填现有百炼密钥；AI_API_URL 填与密钥对应的完整 OpenAI 兼容地址（以 /chat/completions 结尾）；AI_MODEL 填已开通的文字模型（默认qwen-plus，仅在账号支持时可用）。可选AI_MAX_TOKENS须符合模型限制。工作空间密钥必须用配套专属域名。新云函数不会自动继承旧报告云函数的环境变量。
6. 重新编译小程序，点“个人档案”确认启用。模型密钥仅填云端，不能写入小程序或提交Git，也不要发给协作者。

当前环境ID已绑定、功能开关已开启；没有部署或缺少配置时，文字咨询明确降级到本地规则，不宣称写入云端。首次确认前，不发送聊天及个人档案至云端。之前的本机聊天不会自动上传。云端每个用户保留最近40条消息，模型最多读取其中最近20条；长期档案由用户确认更新。

## 用户操作

- 点“个人档案”：查看或修改档案、恢复云端聊天、清除档案/全部云端记忆、关闭云端记忆。关闭不等于删除，界面会说明。
- 在聊天里写“我32岁，备孕半年，周期28天，经期5天”，程序提出档案变更，用户确认才保存。取消档案写入不影响回答；已启用的聊天记忆仍保存本轮文字。
- 当前档案支持年龄、备孕时长、周期/经期长度以及用户确认同步的完整周期记录。不会自动总结为疾病、用药史或其他健康结论。
- 清除档案时同时清除云端对话，避免旧对话继续带出已删除信息；本机聊天与周期记录保留。顶部加号新对话清除本机及已启用的云端聊天，但保留档案和周期记录。
- 本机缓存并不跨设备；云端记录仅在同一微信用户下可恢复，需实机验证。共享设备、不同微信账号的本机缓存隔离尚未实现，不应据此宣称已完成多账号本机隔离。

## 结构化信息采集 → 周期解读

复用现有记录页，不新增页面。首页“排卵周期”→ 标题“结构化信息采集”→ 填写月经起止日期、平均周期、经期长度、身体状态 → 保存 → 选择“查看解读”→ 自动发送“我现在处于周期哪个阶段？”。

保存先写本机；启用云端记忆时，另行确认是否同步完整周期记录到个人档案。同步失败会明确提示本机已保存，不阻断本机解读。

跳转携带刚保存记录，Skill优先使用该记录而不是日期较新的其他历史记录。回答先列出使用的日期、参数和身体状态，再给带有不确定性说明的周期估算。没有记录不报具体阶段。当地日期/记录准确性及模型是否保留数值应实机复核，估算不是排卵确认。

## 复验清单与作品集表述

| 操作 | 观察结果 |
| --- | --- |
| 无周期记录问当前阶段 | 提示补齐信息，不报阶段 |
| 填表勾选疲劳/睡眠不足，保存 | 本机记录与所填字段一致，多选未丢失 |
| 选择查看解读 | 无需手打，引用刚保存日期/参数/状态 |
| 确认保存32岁/备孕半年 | 档案读取包含对应字段 |
| 问“如何安排作息”，再问“那几点睡呢” | 第二次模型请求包含第一次实际问答，不仅显示旧消息 |
| 清除记忆后追问 | 不再读到已删除档案及历史；进行中的旧请求不能回写 |
| 换另一个微信用户请求status | 不出现前一个用户的档案或对话 |

作品集卡片可写“结构化信息采集”（当前是一张周期表单）。说明文案：“补全周期咨询所需的关键记录，为后续个性化解读提供依据。”复验项：“核对信息是否完整收集、正确保存，并传入后续周期分析。”展示流程用“提问 → 填写记录 → 返回解读”；页面总览可按“小暖首页、备孕咨询、结构化信息采集、周期解读、情绪陪伴、反馈与咨询”排列。这些说明不加入产品页面。

## 实际验证边界

Node测试验证确认/拒绝、记录传递、云端用户隔离、历史传入生成、风险优先、存储长度限制和并发清除。模型与数据库均用注入的模拟对象，不能作为真实云部署、真实模型连通性或医疗质量的验收证据。浏览器模拟也不能替代微信原生布局、键盘、授权和真机数据库复核。

本链路复用本地Skill内容作为模型上下文，但未新增服务端RAG检索或知识条目追踪，不宣称已验证完整RAG。高风险当前优先本地风险规则直接展示，不等待云端模型，也不自动上传本轮高风险聊天。

新增医学相关文案位于 companionMemory/core.js 的系统提示与风险回复，以及 utils/skills/cycleSkill.js 的估算说明；均为科普草案，不能代替医生诊断或用药建议，需要专业审核。
