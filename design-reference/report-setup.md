# 报告图片解读：通义千问兼容接口接入

## 配置与部署

1. 开通微信云开发环境，以及阿里云百炼/DashScope 的视觉模型服务。确认服务地域、接口地址和所用模型可用。
2. 微信开发者工具将 cloudfunctions/reportInterpretation 上传部署，并在云端安装依赖。云函数超时设为至少35秒（外部请求超时25秒）。
3. 只在云函数环境变量配置 REPORT_API_KEY。不要放进小程序、Git或聊天。默认 REPORT_API_URL 为 https://dashscope.aliyuncs.com/compatible-mode/v1/chat/completions，默认 REPORT_MODEL 为 qwen-vl-plus；可改成账号支持的视觉模型。可选 REPORT_MAX_TOKENS 需符合所选模型限制。
4. 在 utils/constants.js 设置 REPORT_VISION.enabled=true，envId 填实际微信云环境ID。保持 USE_CLOUD=false。重新编译上传小程序。
5. 真机打开“报告单解读”，选择已遮挡个人信息的清晰报告，点“识别报告数据”；逐项核对名称、数值、单位、参考范围和异常标记，修改错误后点“确认数据并解读”。务必使用非敏感测试报告先验证。

## 数据流和限制

图片经 wx.cloud.callFunction 送入云函数，再请求所配置的视觉模型进行识别。识别成功后先回填核对表，不直接解释；用户确认的字段才进入第二次模型解释请求。代码按照报告原始数值、单位和参考范围组装最终回答，不做单位换算。没有参考范围、多阶段参考值或非单一数值时不强行判定。

单次支持清晰JPG/PNG、最多30个指标。客户端尝试压缩至512KiB以内，失败需裁剪/分批上传；请保留足够清晰度。不是任意报告的完整诊断服务。识别、模型解释均可能错误，临床用途需专业复核。模型输出检查不能替代医疗审核。

代码不将图片保存至云存储，不写报告数据库，不记录原始报告或密钥日志；第三方服务的数据保留规则需另外核实。上传前遮挡姓名、身份证、就诊号和条码等个人信息。关闭 REPORT_VISION.enabled 时不会上传图片；当前已开启，用户点击识别后会发送图片至配置的服务。

当前没有知识库检索接入本报告链路，也没有可宣称的RAG命中记录；报告解释来自用户确认的数据及配置的模型，文字咨询仍来自本地规则。

## 逐字显示

收到完整响应后由前端逐字显示，不是模型流式生成。支持完整原文复制；高风险消息跳过动画，直接展示。退出页面会清理或结束动画。

## 医疗文案审核范围

新增医疗相关文字位于 cloudfunctions/reportInterpretation/core.js（NOTICE、识别/解释提示词、参考范围判断与高风险固定回复）及 components/ImagePreviewCard/ImagePreviewCard.wxml（报告核对提示）。包括：科普参考不替代诊断；核对数值、单位和参考范围；缺少/复杂参考范围不能直接判断；危急标记或严重症状需尽快就医；不根据报告自行用药或停药。均为待专业审核草案，请确认后用于真实服务。
