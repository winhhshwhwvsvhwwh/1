## 回答与路由

- 对不同破折号、全角字符、空格和LH大小写做本地规范化。优先采用更具体的问句，同词命中时优先新增条目，避免旧通用条目抢走。
- 具体主题问题不会被“你好”“我想咨询”等基础寒暄短路。
- 明确同时问到两类主题时，最多合并两条科普解释，建议去重；不会把所有命中的长段落堆到一起。
- 高风险先于找人工等表达，只保留最高风险指导，不追加一般生活建议。
- 中等级用药问题在通用边界之后补充该药物主题的注意事项和必要信息，不给个体剂量、换药或停药方案。
- 信息不够时给出补充信息提示；本地规则不具备任意多轮对话理解，用户下次仍应连同主题提供完整信息。
- 未覆盖的问题继续如实提示知识库没有直接内容，不用泛泛答案掩盖缺失。
